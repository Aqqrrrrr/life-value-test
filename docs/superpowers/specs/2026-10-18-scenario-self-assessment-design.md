# 情境式生活选择自我测评设计

## 定位

产品定位为**基于《高性价比人生指南》的生活选择自我测评**：帮助用户通过日常处境中的选择，识别当前值得调整或进一步思考的生活决策。

它不是 MBTI、人格测试、心理诊断，也不是经过信度/效度验证的标准化量表。产品不得输出人格类型、总分、跨人比较或“完整了解你”的承诺。

## 要解决的问题

现有 22--30 道题以“我是否像这样”的认同式回答为主。它有三个问题：

- 容易使用户选择理想中的自己，而非通常会做的事；
- 好习惯和不良习惯的暗示过于明显，回答像做判断题；
- 即使题量足够，用户仍难把抽象陈述对应到自己的真实处境。

本轮保留原有覆盖范围和按人生阶段适配的能力，但把题目改造成短情境选择。

## 测评结构

1. 用户选择 1--3 个当前人生阶段；可选一个优先展示阶段。优先阶段只影响结果展示顺序。
2. 所有人回答 18 道通用处境题。
3. 每个已选阶段回答 4 道阶段专属处境题。
4. 因此总题量保持为 22、26 或 30 道；不以减少覆盖面换取体验。
5. 题目按 3 个短章节呈现，每完成一组显示下一片生活区域和进度；不在答题中提示对错、分数或人格标签。

### 通用题的六个生活区域

| 生活区域 | 题数 | 覆盖重点 |
| --- | ---: | --- |
| 人身与居住安全 | 3 | 低容错风险、应急准备、居住与出行安全。 |
| 健康、睡眠与就医决策 | 3 | 恢复、症状处理、就医信息与延后成本。 |
| 金钱、消费与风险保障 | 3 | 现金流、消费、核验、保障与损失控制。 |
| 时间、精力与工作选择 | 3 | 负荷、边界、恢复、长期积累。 |
| 关系、家庭与边界 | 3 | 协作、支持网络、照护和沟通边界。 |
| 信息判断、权益与法律风险 | 3 | 来源核验、合同/权益、可逆试错与求助。 |

阶段题仍覆盖在校/毕业过渡、职场起步、稳定工作、独居、转职/失业/重大变动、伴侣/育儿、照护父母或家庭责任增加；每个阶段的四题必须与其真实处境有关，不能重复通用题。

## 题目与选项规则

每题采用同一语法：

> 给出真实且资源受限的生活处境，询问“你通常最可能先怎么做？”，再提供同一场景内的 2--4 种行动与“我没遇过 / 目前不确定”。

- 题干一次只讨论一个处境和一个取舍，不拼接出行、居住、健康等不相关场景。
- 选项表达不同的优先级、信息掌握、风险处理或资源安排，不能把“正确答案”写得显而易见。
- 选项不是道德评判；不使用羞辱、诊断或诱导措辞。
- “我没遇过 / 目前不确定”不计为负向回答。某区域有效回答不足时，结果必须显示信息不足，而非伪造结论。
- 医疗急症、自伤风险、即时危险和进行中的法律程序不制作成延迟行动或娱乐化题目；页面只在用户主动寻求这类帮助时提供直接的现实第一步，不把其作为常规评分素材。

## 结果与判读

不生成总分或人格类型。系统根据有效回答、已选阶段和可追溯的指南条目，输出最多三张**优先复盘行动卡**：

1. 先降低高损失风险；
2. 减少被透支的资源；
3. 补上信息、权益或支持缺口。

每张卡必须包含：

- 从用户本次回答得出的、非人格化的观察；
- 可能被忽略的成本或收益；
- 一个低门槛、可在本周完成的第一步；
- 适用条件、限制和必要时的争议提示；
- 《高性价比人生指南》的具体章节、条目标题和原始出处。

页面可同时展示用户已经表现出的选择优势，但不得用它代替风险与边界说明。结论语言使用“从这组处境看”“当前值得优先回看”，不能宣称永久特质或医学/法律结论。

## 体验与回访

- 答题体验使用“生活选择地图”的轻量表达：六个生活区域、短场景卡、清晰进度和最终的地图式结果。
- 趣味性来自把指南建议映射到用户的真实选择，不来自积分、排名、连续签到或升级。
- 结果页提供按生活区域进行一次“小复盘”的入口，供用户在遇到新处境时重新使用；不设计强制每日打卡或让高风险议题变成刷分任务。

## 内容与数据边界

- 所有行动卡只可由指南中的完整条目支撑；不编造数字、收益、适用条件或证据等级。
- “待核实/TODO”内容不能作为唯一确定结论；存在争议的条目须呈现争议与限制。
- 结果代表本次自述的决策快照，不代表人格、能力、健康状况或未来表现。
- 用户可多选阶段；回答和阶段信息仅用于本次结果与已获授权的报告流程，继续遵循现有账户、兑换与权限边界。

## 验收标准

- 每次测评仍严格产生 22、26 或 30 道题，且 18 道通用题覆盖六个区域各三题。
- 任何题干与选项均处在同一生活场景；每题都有“未遇过/不确定”的非惩罚性出口。
- 各阶段四题与阶段处境相关，并与通用题去重。
- 结果最多三张优先复盘行动卡；不出现人格类型、总分、排行榜或跨领域名次。
- 信息不足时明确说明，不能输出无依据建议。
- 每张行动卡都能回指具体指南条目，并呈现成本、证据、适用条件以及需要时的争议信息。
- 移动端用户可完成阶段选择、22--30 道作答、查看地图式结果和进入小复盘。

## 需要验证的假设

- 情境题比认同式题更能降低社会期许偏差、提升用户对题目的贴合感；这是假设，须通过可用性测试验证。
- 保持 22--30 题的覆盖面不会显著损害移动端完成率；须观察完成率、每题耗时、退出位置和结果后实际点击率。
- “优先复盘行动卡”是否足够清晰、有用，须以用户能否复述一个具体的下一步来检验，而非只看满意度。
