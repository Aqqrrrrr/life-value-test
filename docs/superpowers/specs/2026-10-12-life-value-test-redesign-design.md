# 人生性价比测试 V1 改版设计

日期：2026-10-12

## 目标

将现有的 24 道行动选择题改为“决策风格画像 + 处境相关行动清单”。产品服务于想使用《高性价比人生指南》、但不愿从数百条内容中自行筛选的用户。它是自我反思与行动筛选工具，不是心理诊断、医疗建议或正式人格测评。

首发假设是 22–35 岁、正处于工作、居住、金钱、关系或家庭责任变化中的移动端用户。该假设须由后续自愿、粗粒度的产品数据验证，不能表述为已证实的人口统计结论。

## 非目标

- 不将寿命、时间精力、金钱与人身自由合并为“人生总分”。
- 不用用户的风格分数改变安全、法律或医学建议的事实优先级。
- 不将急救、自伤风险、正在进行的法律程序做成延迟行动的测试题。
- 不在 V1 收集病史、收入、具体住址、身份证件或其他高敏感信息。
- 不在 V1 新增站内支付、邮件服务或自动推送。

## 用户流程

```text
开始测试
  -> 安全提示门
  -> 6 道处境筛选题（不计分）
  -> 12 道决策风格题（5 级量表）
  -> 本地结果页：画像 + 三条分口径行动建议
  -> 已购买且完成邮箱验证的用户：解锁详细报告
```

安全提示门若识别到紧急危险、严重自伤想法、医疗急症或正在进行的法律程序，立即退出测评并提供首步求助或处置路径。

## 处境筛选

处境题只影响条目适用性，不进入人格分数。

| 字段 | 选项/规则 |
|---|---|
| 安全提示门 | 紧急场景直接旁路；否则继续。 |
| 当前阶段 | 在读、刚工作、稳定工作、家庭责任增加、退休前后、不说明。 |
| 当前关注方向 | 安全健康、钱与权益、时间精力、工作技能、关系家庭；最多选两项。 |
| 家庭责任 | 主要照顾自己、伴侣、未成年孩子、老人照护；可多选。 |
| 居住与出行 | 租住、自住、驾车、骑电动车/摩托、公共交通/步行；可多选。 |
| 当前稀缺资源 | 钱、时间、精力、无明显限制。 |

医疗严格适用性需依赖病史或临床判断的条目，在 V1 不自动推荐。

## 决策风格题

统一使用五级回答：非常不像我、比较不像我、说不清、比较像我、非常像我。每个维度 3 题，其中至少 1 题反向计分。

### 防护前置 ↔ 机会推进

1. 做一个新决定前，我会先排除“出一次事就很难挽回”的风险。
2. 即使看上去机会很好，只要后果难承受，我通常会先暂缓。
3. 为了获得可能更大的收益，我愿意接受一些本可避免的风险。（反向）

### 证据核实 ↔ 快速判断

1. 遇到健康、金钱或权益建议时，我会先看适用条件和依据。
2. 身边多数人都在做，通常已经足够让我相信。（反向）
3. 两种说法冲突时，我愿意多花一点时间确认来源。

### 低摩擦行动 ↔ 系统投入

1. 我更容易先完成一个小而明确的动作，再决定是否继续投入。
2. 我会把“以后再做”改成具体的时间、地点或触发条件。
3. 我宁愿等到计划完整，也不愿先做一个不完美的小步骤。（反向）

### 自主处理 ↔ 协作求助

1. 涉及健康、法律或钱的复杂问题，我会较早寻求专业或制度支持。
2. 除非实在没办法，我通常倾向一个人把问题扛过去。（反向）
3. 我会让家人、朋友或工具参与提醒与执行，而不只靠意志力。

## 画像与结果

结果采用“主策略 + 辅助标签”，避免声称拥有临床或人格量表效度。

主策略使用前两个维度的组合：

- 稳健验证型：防护前置 + 证据核实；
- 稳健行动型：防护前置 + 低摩擦行动；
- 机会验证型：机会推进 + 证据核实；
- 机会推进型：机会推进 + 快速行动。

辅助标签来自其余明显维度：自主推进、协作求助、系统规划。示例：`稳健验证型 · 协作求助倾向`。

结果页必须说明画像可随处境和时间改变，不能作为能力、道德或医疗结论。

## 行动推荐

### 条目数据

每个入选条目必须保留以下字段：

- 章节、条目标题、原始出处链接；
- 收益口径：安全健康、时间精力、金钱权益；
- 钱、时间、毅力成本；
- 性价比档位与证据等级；
- 适用条件、争议、待核实状态；
- 处境标签，例如租住、骑行、孩子、老人、求职。

### 选择规则

1. 根据处境筛掉不适用的条目。
2. 在同一收益口径内，依据指南的性价比档位、证据等级与适用性选择。
3. 最多分别推荐一条安全健康、时间精力、金钱权益行动。
4. 无安全适用条目时显示“暂不自动推荐”，不能凑数。
5. 带“待核实”的条目不能作为唯一确定推荐；带“争议”的条目必须显示争议提示。
6. 画像仅影响行动卡的说明和执行提示，不影响条目的事实排序。

三个行动卡必须独立显示，禁止跨收益口径排序为“最值得的三件事”。

## 呈现规则

每张行动卡显示：为什么与你有关、首步行动、成本、证据、适用限制、指南出处。

不同画像的差异只在呈现方式：

- 稳健验证型优先显示证据和适用条件；
- 低摩擦行动倾向优先显示今天能完成的首步；
- 系统规划倾向显示后续提醒或清单；
- 协作求助倾向提示适合的支持对象或制度渠道。

## 数据与权限

- 免费测试默认仅在浏览器本地保存。
- 付费详细报告只在已验证邮箱账户具备有效 entitlement 时读取。
- 服务端按 `user_id + entitlement` 校验报告访问，不能信任 URL 参数。
- 年龄段和处境如用于后续产品分析，必须粗粒度、可跳过，并在产品界面说明用途。

## 验收标准

- 6 道处境题不影响 12 道风格题的分数。
- 反向题和各维度分数计算可由自动测试验证。
- 每张行动卡回指到指南的具体章节和条目标题，不生成正文没有的数字。
- 不同收益口径不产生总分或跨口径总排序。
- 风格差异不会降低安全、法律、医疗条目的筛选标准。
- 紧急场景触发旁路，且不进入常规题目或延迟建议。
- 争议、待核实和不适用条目按规则展示或排除。
- 未绑定邮箱或无 entitlement 的用户不能访问详细报告。

## 实施范围

现有前端题库、测试页、结果页和报告 API 将改为读取新的题型与条目元数据。V1 保持现有账户、兑换码与报告解锁架构，不接入新的支付或邮件供应商。
