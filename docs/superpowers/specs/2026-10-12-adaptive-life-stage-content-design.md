# 自适应人生阶段题库与结果内容优化

## 背景与目标

现有测试的技术链路、结果输出和预览部署均已可用，但固定题组容易出现题干与选项跨场景、用户处境覆盖不足的问题。本轮将测试改为按人生阶段自适应的题库：服务想快速吸收《高性价比人生指南》、却不愿通读全文的用户，输出可复盘、可追溯且与当下处境有关的建议。

该产品是自我反思与决策辅助工具，不是心理、医疗或人格诊断。它不声称测得稳定人格真相或给出“人生总分”。

## 范围

### 包含

- 用户在开始时选择 1--3 个当前生活阶段，并可指定一个优先展示阶段。
- 全员完成 18 道核心题；每个已选阶段完成 4 道专属题；总数严格为 22、26 或 30 道。
- 建立 7 个阶段模块和每模块 4 道可追溯处境题。
- 结果页分开呈现安全健康、时间精力、钱与权益，以及按阶段组织的行动建议。
- 为题目、行动、出处、证据、成本、争议与适用条件建立可测试的数据边界。
- 保留免费结果、已解锁详细报告、兑换码、邮箱绑定和权限校验流程。

### 不包含

- 人格诊断、医疗/法律意见、人生总分或跨领域排名。
- 自动随机抽题、推荐模型、用户画像持久化或支付流程改造。
- 用普通测验题处理急救、自伤风险、即时危险或正在进行的法律程序。

## 用户输入与测评流程

1. 首页/测试页给出低打扰的紧急提示，但不开场询问或要求用户自我标记风险。
2. 用户选择 1--3 个当前生活阶段：在校/毕业过渡、职场起步、稳定工作、独居、转职/失业/重大变动、伴侣/育儿、照护父母或家庭责任增加。
3. 用户可选择其中一个“此刻最想改善”的阶段；这只控制结果的展示顺序，不影响计分或建议资格。
4. 用户完成固定的 18 道核心题和每个选择阶段的 4 道专属题。
5. 如用户在后续明确表示医疗急症、自伤风险或即时危险，停止该题的普通评分并显示简短、直接的现实行动提示。进行中的法律程序不作为测验题，改为提示优先获取合格的专业法律协助。
6. 提交后仅保存本设备的结果快照，并显示免费结果；已具备有效权限的用户可查看详细报告。

## 题库结构

### 核心题（18 道）

| 模块 | 数量 | 目的 |
| --- | ---: | --- |
| 安全与不可逆风险 | 4 | 识别对高损失、低容错风险的关注方式。 |
| 健康、精力与恢复 | 4 | 识别精力瓶颈、恢复和延后成本。 |
| 金钱、消费与权益 | 4 | 识别核验、现金流与权益保护习惯。 |
| 证据、风险判断与信息核验 | 3 | 识别核实来源、处理不确定性和可逆试错的偏好。 |
| 执行方式、支持网络与求助 | 3 | 识别拆解行动、获得支持和复盘的方式。 |

核心题只能生成决策风格维度，不能因用户属于某个阶段而加减分。

### 阶段题（7 × 4 道）

| 阶段 | 处境类别 |
| --- | --- |
| 在校/毕业过渡 | 求职与选择、租房与搬迁、第一笔大额支出、支持网络。 |
| 职场起步 | 合同与劳动权益、反馈与学习、加班/通勤、职业尝试。 |
| 稳定工作 | 工作边界、精力恢复、长期储蓄与保障、职业发展停滞。 |
| 独居 | 居住安全、紧急预案、生活成本、孤立与日常支持。 |
| 转职/失业/重大变动 | 现金流、信息核验、过渡安排、压力与求助。 |
| 伴侣/育儿 | 共同决策、家庭预算、居家与儿童安全、时间分工。 |
| 照护父母/家庭责任增加 | 照护分工、医疗与紧急信息、家庭财务/权益、照护者恢复。 |

阶段题只决定该处境下的关注点和建议适用条件，不能被解释为人格特征。第一版不随机抽题：相同阶段组合必须得到相同题目和题序。

## 内容规则

- 每题只描述一个明确处境和一项清楚取舍；选项必须属于同一场景，不能跨场景拼接。
- 选项表达不同决策方式，不制造显而易见的正确答案，不使用羞辱、诱导或诊断性措辞。
- 任何行动卡必须引用指南中的完整条目，使用固定版本链接；不得编造正文不存在的数字、收益或条件。
- “待核实/TODO”条目不能成为唯一确定建议；有争议条目必须展示实际限制、争议提示和适用边界。
- 结果不会合并安全健康、时间精力、钱与权益为总分或排名。

## 结果设计

1. 顶部说明：选择的生活阶段以及“结果是当下决策快照，会随处境变化”的免责声明。
2. 决策风格：由核心题生成，说明优势、可能盲点和不确定性，不贴永久人格标签。
3. 三个独立行动栏：安全健康、时间精力、钱与权益；各自展示匹配理由、适用条件、第一步、钱/时间/毅力成本、证据等级、出处和争议提示。
4. 阶段行动：每个所选阶段最多展示两条；优先阶段先展示。没有足够匹配内容时明确“暂不自动推荐”。
5. 去重与冲突：同一行动只展示一次并合并适用条件；需要资源权衡时只给出优先级原则（即时安全优先、现金流与法定权益优先于可延后体验），不下相互冲突的立即行动指令。
6. 免费结果须让用户判断测试价值；详细报告只在服务端确认 `user_id + entitlement` 后提供更完整的复盘内容。

## 数据与组件边界

- 题库模块负责问题、选项、所属阶段、所映射维度和处境信号；不得自行渲染页面。
- 行动目录负责来源、成本、证据、适用条件、限制与展示资料；不得从未验证内容推断数值。
- 测评快照只记录回答、阶段选择、优先阶段和计算结果；不得把邮箱、订单号或明文兑换码写入 URL 或浏览器公开状态。
- 结果组件只渲染经过选择器筛选后的独立视角和阶段行动；服务端报告接口仍只负责授权，不把可生成的个性化内容伪装为服务器私密数据。

## 验收与测试

- 阶段选择至少一项、至多三项，优先阶段必须属于已选阶段。
- 七个阶段均有四道独立题；每种选择得到 22、26 或 30 道题且题序稳定。
- 所有题目的题干/选项处于同一生活场景；核心题和阶段题的计分、信号与解释隔离。
- 每个已选阶段有至少一条可追溯建议或明确的“不自动推荐”状态。
- 三个视角不出现总分或跨领域名次；多阶段建议去重且不冲突。
- 每张行动卡有可点击的固定版本出处、成本、证据与适用条件；争议/待核实规则被测试覆盖。
- 明确触发急症、自伤风险、即时危险或进行中法律程序时不会继续被当作普通风格题评分。
- 免费/已解锁报告均可在移动端完成浏览；报告授权继续只信任会话与未撤销的 entitlement。

## 成功标准

试用者应能说出至少两道题为何与自己相关，并至少指出两至三项“本周能做”的行动。发布前必须消除题干与选项跨场景的问题，且每个结果动作可回指指南的具体条目。
